# 安装与使用（新手先看这一页）

> 对应版本：dsh-cv 0.5.0 ｜ 完整流程细节见 [用户手册](user-guide.md) ｜ 项目能力概览见 [README](../README.md) ｜ 变更见 [CHANGELOG](../CHANGELOG.md)

本页只回答两件事：**怎么装**、**装完怎么用**。所有命令可直接复制。

---

## 0. 你需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| **DeepSeek Harness（DSH）** | 已安装 | 提供会话入口与技能加载；没有 DSH 只能用下面的脚本，不能用对话建档/写简历 |
| **PowerShell 7（`pwsh`）** | 建议 7.x | 安装脚本用；`.ps1` 为无 BOM UTF-8，脚本头注明"请用 PowerShell 7 执行"（Windows 自带 5.1 未验证） |
| **Node.js** | ≥ 16 | 跑生成器与三个校验门槛；生成/校验/审计/自检**零第三方依赖** |
| **magicv.art 账号** | 可选 | 渲染与导出 PDF 用；不用它也能生成 JSON |
| **playwright-core + 本机 Chrome** | 可选 | 只做「真实渲染验收」时需要：本仓库执行 `npm i -D playwright-core`（或在别处装好，用 `$env:PLAYWRIGHT_DIR` 指向那个目录）；**浏览器路径不用配**，脚本会自动探测 |

**权限**：**不需要管理员权限**——安装用目录联接（Junction）而非符号链接。

**装完先自检**（零依赖，随时可跑）：

```powershell
node scripts\check.mjs      # 或 npm run check：脚本语法 / JSON / 技能完整性 / 零硬编码路径 / 文档链接 / manifest 一致
```

## 1. 安装（三步）

```powershell
git clone https://github.com/specterxueye/dsh-cv.git
cd dsh-cv
pwsh -NoProfile -File scripts\install.ps1
```

- **克隆到任意目录都行**（含空格、中文路径均支持），脚本路径无关、可重复执行（幂等）。
- Git 慢/不可用：在 GitHub 页面下载 ZIP → 解压 → 在该目录执行第 3 条命令。
- 报执行策略错误时：`pwsh -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1`
- 只想先看看要做什么：加 `-DryRun`，不写任何东西。

脚本做五件事：

1. 设用户级环境变量 `DSH_CV_ROOT` = 仓库根（模型据此定位规则库）
2. **遍历 `preset\skills\*` 全量建立技能联接** `<DSH_HOME>\skills\<技能名>` → 仓库同名目录（新增技能子目录无需改脚本）
3. 渲染预设注册壳到 `<DSH_HOME>\.agent-presets\resume-master\`（模板注入本机路径）
4. **安装自检**（环境变量 / 技能联接 / 注册壳）
5. 打印摘要与「下一步怎么用」

---

## 2. 装完怎么确认

脚本末尾会打印自检结果，四项全绿即装好：

```
== 安装自检 ==
  [OK]  DSH_CV_ROOT（用户级）= D:\...\dsh-cv
  [OK]  技能联接 4/4 就位：cv-intake, interview-pitch, mock-interview, resume-writing
  [OK]  预设注册壳就绪且已注入本机根：D:\dsh\.agent-presets\resume-master
  自检结果：3/3 通过
```

想手工核对：

```powershell
# ① 环境变量（用户级）
[Environment]::GetEnvironmentVariable('DSH_CV_ROOT','User')

# ② 技能联接：应看到 4 条，且 LinkType 为 Junction / SymbolicLink
Get-ChildItem "$env:DSH_HOME\skills" -Force |
  Where-Object LinkType | Select-Object Name, LinkType, Target

# ③ 注册壳
Test-Path "$env:DSH_HOME\.agent-presets\resume-master\agent.cordis.yml"
```

> `DSH_HOME` 未设置时默认 `~/.dsh`（Windows 即 `C:\Users\<你>\.dsh`）。

**②显示 4 条中缺哪条，会话里就用不了哪个技能**——缺了就重跑 `install.ps1`。

## 3. 第一次使用（走完一份简历）

回到 DSH 会话（环境变量与技能在**新会话**生效），按顺序说这些话即可：

| 步 | 你说 | 会发生什么 |
|---|---|---|
| 1 | **「帮我写简历」** | 加载 `cv-intake` 开始**建档**：先问你要现成材料（旧简历/成绩单/证书/项目仓库）；没有就走 7 轮提问，**每轮整批问、每题带推荐答案、可答"跳过"** |
| 2 | 贴 **JD 文字** 或 **图片路径** | 出《JD 理解卡》：硬性/软性/加分/关键词表/**缺口清单**/公司风格；图片识别不确定会列出来让你确认 |
| 3 | **「按这个 JD 选项目」** | 候选池按**六维打分**，一轮给出「点亮哪 3-4 项 / 收起哪几项 / 命中了哪条 JD 要求」，你逐项裁决 |
| 4 | 看《改动申请单》并**明确批准** | 申请单写着：改哪条 / 现状 / 拟改成什么 / JD 依据 / 影响 / **哪些不动**。说"你看着办"**不算批准** |
| 5 | **「生成」** | 出 magicv JSON + 三重校验（结构 / 数字溯源 / 改动合规）；然后到 https://magicv.art 导入 → 导出 PDF |

**触发词速查**：建档 / 写简历 / 分析 JD / 按 JD 选项目 / 生成 magicv JSON / 项目讲稿 / 模拟面试。

其他入口（二选一即可，技能对所有会话生效）：

- **不选预设**：任何会话说触发词就会加载技能（推荐，装好即用）。
- **选「简历大师」预设**：新开会话时在预设选择器里选它，可额外带上一份精简人设与工作流提示。

## 4. 日常使用（第二份简历起）

- 建档只需一次：之后换岗位只走 **贴 JD → 选项目 → 批准申请单 → 生成**。
- 同一份事实基线可产出多份岗位版本，互不覆盖（写入 `users\<用户名>\output\`）。
- 面试环节（交付后可选）：
  - **「生成项目讲稿」** → `interview-pitch`：按 JD 角度出口述稿（含 2-3 条可能追问）
  - **「模拟面试」** → `mock-interview`：双模式（友好复盘 / 高压追问）× 三类型（BQ / JD 面 / 混合）

## 5. 升级 · 换电脑 · 卸载

**升级**（幂等，随时可跑）：

```powershell
cd <仓库目录>
git pull
pwsh -NoProfile -File scripts\install.ps1
```

**换电脑 / 换目录**：新机 `clone`（或拷仓库）+ 跑 `install.ps1`；再把旧机 `users\<用户名>\` 拷过来即可续用历史档案。个人数据不入库，必须自己搬。

**卸载**：

```powershell
# ① 删技能联接（只删链接，不删仓库源文件）
Get-ChildItem "$env:DSH_HOME\skills" -Force | Where-Object LinkType |
  Where-Object { $_.Target -like "*dsh-cv*" } | ForEach-Object { cmd /c rmdir "$($_.FullName)" }

# ② 删预设注册壳
Remove-Item "$env:DSH_HOME\.agent-presets\resume-master" -Recurse -Force

# ③ 删环境变量
[Environment]::SetEnvironmentVariable('DSH_CV_ROOT', $null, 'User')
```

仓库目录与 `users\` 个人数据自行决定是否保留。

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `pwsh` 不是可识别的命令 | 装 PowerShell 7；或改用完整路径 `& "$env:ProgramFiles\PowerShell\7\pwsh.exe"` |
| 报"禁止运行脚本"（执行策略） | 加 `-ExecutionPolicy Bypass` 重跑（见 §1） |
| 技能在会话里看不到 | ①确认自检 4/4；②**新开**一个会话（技能目录与环境变量热生效有延迟）；③技能名必须和 `preset\skills\` 下的目录名一致 |
| 告警"目标已存在但非联接" | `<DSH_HOME>\skills\<名字>` 下是真实目录不是链接 → 确认无用后删掉再重跑 |
| 新会话里 `$env:DSH_CV_ROOT` 为空 | 用户级变量未写入或被清理；重跑脚本，或临时 `$env:DSH_CV_ROOT="<仓库根>"` |
| 预设选择器里没有「简历大师」 | 不影响使用（技能已全局生效）；要预设就重跑 `sync-preset.ps1` 检查注册壳 |
| 图片 JD 识别不出来 | 依赖视觉桥可用性；直接贴文字同样可用 |
| 生成/校验报找不到文件 | 路径含空格/中文的，命令里**必须加引号**：`node "scripts\validate-resume.mjs" "<路径>"` |
| 想放到 D 盘或中文目录 | 可以，安装脚本路径无关 |
| 没有 DSH 能用吗 | 生成器与校验器能用（只要 Node）：`node "scripts\build-resume.mjs" --help`；建档、JD 识别、选项目等对话环节需要 DSH |

## 7. 这份插件里有什么（4 个技能）

| 技能 | 干什么 | 什么时候被加载 |
|---|---|---|
| `cv-intake` | **拷问式建档**（round 提问 + 推荐答案，可自查项派子代理去查）＋**按 JD 取舍项目**（六维打分 → 你裁决） | 建档/选项目时，或被简历工作流链式载入 |
| `resume-writing` | 写作规则库与工作流：0-7 优化清单、真实性铁律、magicv JSON 金标准、三重校验门槛 | 说"写简历/改简历/分析 JD/生成 JSON" |
| `interview-pitch` | 项目讲稿（按 JD 角度，含可能追问） | 说"项目讲稿/面试怎么介绍" |
| `mock-interview` | 模拟面试（双模式 × 三类型，含最弱回答改善版） | 说"模拟面试/面试练习" |

> 真实性铁律：**简历只写真实优势，绝不编造**；每个数字要能溯源，查不到就降级或删掉。
