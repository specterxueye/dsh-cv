# 使用手册

本插件在 DeepSeek Harness 中协助整理事实、按岗位改写简历，并提供讲稿和模拟面试。安装与移除见 [安装与使用](安装与使用.md)，完整 AI 执行规则见 [权威工作流](../preset/prompts/02-workflow.md)。

## 从已有材料开始

给出当前简历、项目说明或其他你允许读取的材料，再提供目标岗位 JD。可以说明「先给修改方案，不要改原稿」。已有信息先复用；遇到职责冲突、估计数字或关键缺失，再集中核对。没有材料也可通过访谈逐步整理。

首次创建需要确认要展示哪些经历；已有稿修改需要同时确认改写范围。批准前可调整项目、栏目、页数与表达风格。原稿保留，成品使用新文件名；隐藏某项目不等于删除项目事实。

## 文件保存在哪里

明确选择一个稳定的个人目录，每位用户分别保存事实基线、来源、偏好和 output 成品。插件资源目录只读，更新或移除插件不影响个人目录。旧 users 目录不自动迁移。

技能加载结果会提供资源基目录，用它定位包内脚本；不要依赖 DSH_CV_ROOT。生成器默认将输出放到事实基线同级的 output，重复文件名失败；确认替换时才用 --force。

## 如何看检查结果

- 结构检查：字段类型、菜单与内容、富文本格式等机器合同。
- 数字来源命中：检查被扫描数字是否在有效来源中出现。缺失来源报错；同数出现不能证明其对象、职责、单位或时间真实。
- 改动核对：已有稿与新稿对照，检查是否超出批准字段。首次没有原稿时不虚构蓝本。
- 排版：本地量高仅近似。在线命令会把选定 JSON 导入 MagicV，核对正文锚点并测量文本矩形；缺标记或失败不能当作通过。最终查看导出 PDF 的页数、文字、照片与栏目完整性。

当前网页工具只给单页几何结论，多页需求需另行核对。任何可见文字或版式变化后，都不能继承旧排版结论。

## MagicV 与原稿的关系

JSON 可导入 MagicV 预览和导出 PDF。每次导入可能创建新记录，用户在编辑器中的手改也可能与本地 JSON 分叉。保存导出文件，确认哪一份是当前稿，再把有效修改回流到事实与本地稿；不要自动覆盖你在编辑器中做的更改。

## 面试准备

简历交付后，可说「按这个 JD 写项目讲稿」，或「开始模拟面试」。讲稿使用同一份事实来源；模拟时一次问一题，明确区分实际经历追问、岗位知识题和假设情景题。练习中的设想不会自动变成个人经历。

## 隐私

个人文件默认保存在本地选定目录，并与插件生命周期分离。向 DSH 提供的材料由你配置的模型处理；可选 MagicV 导入或在线测量会交给外部编辑器。项目没有核验第三方保留政策，不保证端到端离线。只提供本任务必要的信息，删除个人资料和迁移位置均由本人决定。

问题与验收进度见 [公开发布优化计划](公开发布优化计划.md)。
