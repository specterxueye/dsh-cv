# 公文汇报与协作句式库（扩充）

> **语料性质说明**：通用句式资产（占位数据为示意），供生成器/规则库引用；仅用于简历中的"能力表述"，不代表任何人的真实经历，占位值必须由真实信息替换。
> **来源方向**：湖南日报新媒体（央国企动作词：起草/流转/核验/归档/零差错、公文类关键词）；四川数据集团/榆林大数据公告（国企素养语言：遵规守法/诚信廉洁/团结协作/担当）；队内第一轮央国企语料（文字功底、汇报写作、党团活动）；通用职场写作惯例（技术评审/PPT/跨部门协作属于公开的职场表达惯例，本文件在此层面引用，具体绩效数字仍须真实）。
> **注意**：以下句式是"措辞模板"，不是事实模板——填入的成果、数字、角色必须可溯源。

---

## 一、国企公文风句式

### 动词/短语词库
起草、拟稿、修改、审定、呈报、印发、归档、流转、核验、贯彻、落实、落地、推动、会同、协调、统筹、组织、汇总、上报、通报、总结、提炼、规范、完善、健全、强化、压实、闭环管理、清单化、台账化、挂图作战（按真实使用）。

### 句式（占位示意，按场景选句）
- **文档类**："起草 XX 工作汇报/方案/通知 X 份，经审定后印发，覆盖 XX 个部门；同步归档 X 项材料，零差错。"
- **活动/会议类**："统筹 XX 会议/活动 X 场，协调 X 个部门、XX 人次参与，形成会议纪要 X 份并跟踪落实。"
- **党务/团务类**："协助整理入党/团组织材料 XX 份，核验信息零差错；组织主题党日/团日活动 X 场，覆盖 XX 人次。"
- **数据/报表类**："汇总统计 XX 数据 X 指标，输出日报/月报 X 期，确保口径一致、数据准确。"

### 使用提醒
公文风句式**只用于真实做过的事务**；"贯彻/落实/压实"类词在简历中需有"动作+对象"支撑，避免空动词堆砌。

## 二、技术评审风句式

### 动词/短语词库
评审、答辩、演示、验收、对标、选型、定稿、风险评估、缺陷闭环、回归、里程碑、评审会、结论、建议、指标达成、量化验收、现场评审（按真实使用）。

### 句式（占位示意）
- **评审/答辩**："在 XX 课程设计/项目评审会上完成系统演示与答辩，从 XX 维度说明设计取舍，评审通过。"
- **验收类**："按 XX 验收标准完成功能自测与回归，指标达成 X 项，形成验收材料 X 份。"
- **技术选型**："参与 XX 技术选型/方案对比，输出对比表（X 方案 vs Y 方案），最终确定 XX 并落地。"
- **缺陷/风险**："整理测试中发现的问题（X 个）并按严重度分级，推动修改后回归通过，线上/最终版本 0 缺陷。"
- **文档**："编写设计说明书/需求文档/测试报告 X 份（题目内容按真实项目），评审意见完成闭环。"

### 使用提醒
技术评审类表述按"真实做过什么"写；"评审通过/验收通过"类结论必须有对应的真实场合（课程答辩、实验验收、项目演示）。

## 三、PPT / 汇报能力表述

### 动词/短语词库
宣讲、演示、汇报、讲解、展示、结构化表达、结论先行、可视化、图表呈现、受众视角、层层递进、答疑、互动（按真实使用）。

### 句式（占位示意）
- **宣讲/讲解**："面向 XX 群体进行 XX 政策/产品/方案宣讲 X 场，累计覆盖 XX 人次，现场答疑 X 项。"
- **汇报/展示**："独立制作并汇报 XX 主题 PPT（X 页），以数据图表+结论结构呈现，获 [老师/负责人/评委] 认可。"
- **可视化**："用 Excel/PPT/ECharts 将 XX 数据转化为图表，支撑汇报结论 X 项。"
- **教学/带教**："面向低年级同学进行 XX 技能教学/分享（X 人次），制作讲义/示例 X 份。"

### 使用提醒
"宣讲/汇报"经历需真实（如返家乡政策宣讲、课堂汇报、社团分享）；PPT 能力、宣讲能力是央国企综合岗/解决方案岗的加分信号（对齐第一轮"文字功底"规律）。

## 四、跨部门协作句式

### 动词/短语词库
协调、对接、拉通、同步、推进、配合、联动、接口人、闭环、反馈、资源协调、跨团队、需求对齐、风险预警、里程碑同步（按真实使用）。

### 句式（占位示意）
- **接口/联调**："作为前端/XX 侧接口负责人，与后端/XX 团队进行接口联调，明确并闭环 XX 个问题，保障上线节点。"
- **跨团队推进**："协调 X 个小组/部门分工，建立进度同步机制（周会/日报），推动 XX 项目按期交付。"
- **资源/协作**："对接 XX 单位/校外资源（X 家），完成 XX 事项落地，形成合作成果 X 项。"
- **风险预警**："在 XX 项目中发现进度/接口风险 X 项，及时同步负责人并推动解决，避免影响交付。"
- **带教/梯队**："制定 X 规范/流程文件（第一版），培训/带教 X 人，形成可复用机制。"

### 使用提醒
"跨部门/跨团队"表述在简历中是组织协作能力的证据；**"对接/协调"必须有真实对象与成果**，不写"协调能力强"这类无证据断言。
