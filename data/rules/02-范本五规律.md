# 技能与表达的五条参考

类型：维护者对表达方式的归纳，2026-10-19；不是招聘效果数据或本人经历。适用：按实际岗位和材料选择，不能作为数字来源。

| 原则 | 表达示意 |
|---|---|
| 按能力域组织 | 数据处理、服务开发、实验分析等采用实际相关领域 |
| 熟练度有边界 | 熟练、熟悉、了解与实际掌握程度一致，不自动升级 |
| 工具名称具体 | 使用过的语言、库、设备或方法写具体名称 |
| 落到动作与产出 | 用某工具完成某任务，解决什么问题，获得什么已确认结果 |
| 一条聚焦一件事 | 先能力结论，再具体场景与依据，避免重复工具清单 |

示意句式：“在【实际角色】下，使用【已掌握工具】完成【具体动作】，形成【已确认产出】。”占位内容不是用户事实；没有可信量化时可以写清具体结果，不必硬加数字。参与和协助可明确贡献范围，不能自动改成独立完成。
