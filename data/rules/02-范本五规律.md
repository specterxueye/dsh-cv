# 02-范本五规律（技能优势写法 · 提炼自真实范本审校）

> 来源：OpenViking 记忆「简历技能优势优化方案」（2026-08 针对真实简历审校时提炼）

## 五规律（每条命中率：HR 觉得专业 vs 觉得堆砌）

| 规律 | 范本实例 | 为什么 HR 觉得专业 |
|------|---------|------------------|
| ① 按能力域分类，一项一个标题 | 分析仪器操作 / 科研绘图与数据处理 / AI 与计算机视觉 | 一眼看清有几类硬技能，不堆砌 |
| ② 熟练程度分级，用词讲究 | "熟练掌握""熟练运用""通过…考试" | 不夸大、可信 |
| ③ 工具/技术带具体名称 | Vue 3、ECharts、YOLOv5、SQL Server、Origin、PR | 对号入座，HR 快速判断匹配度 |
| ④ 每项都落到"能干什么" | "数据解读与异常识别""图表自适应""mAP@0.5 0.9744" | 从"会工具"升级为"能产出"，有画面感 |
| ⑤ 一条一句，先总后分 | "熟练掌握 A、B、C…，具备 XX 能力，可用于 XX" | 信息密度高、无空话、可快速扫读 |

## 技能条目模板（五规律落地）

> **技能域标题**：熟练运用/熟悉**工具A、工具B、工具C**完成**具体场景**（可量化产出）；可独立完成**负责任务**。

示例（真实基线）：
- **AI 与计算机视觉**：熟练运用 Python、PyTorch、OpenCV、YOLOv5 完成目标检测全流程（数据集构建、训练、评估、推理、可视化），验证集 mAP@0.5 0.9744；可独立读懂训练曲线、PR 曲线与混淆矩阵并定位问题。
- **前端与数据可视化**：熟练运用 Vue 3、Element Plus、ECharts、高德地图，可独立完成图表自适应、全屏适配与 PDF 导出，用于真实政务项目 20+ 页面的信息呈现。
- **后端与数据库**：熟悉 SQL Server / MySQL，可编写视图、存储过程与触发器，完成主外键约束设计的业务数据库方案。
- **语言与编程基础**：大学英语四级 459 分、六级 450 分，可阅读英文技术文献；熟悉 C/C++，掌握常用数据结构与算法，具备快速建模与编码实现能力。

## 反例（绝对禁止）

- "学习能力强、抗压能力强、沟通能力强"（无论证的空话）
- "熟练使用各种办公软件"（工具无名称、无用途）
- 一条罗列 20 个工具名（无分类、无熟练度、无产出）
