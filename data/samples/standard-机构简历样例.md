# ★★★ 标准参照：机构改写的简历样例（最高优先级素材 · 用户提供）

> 来源：用户提供的某求职机构改写样例（截图，华南理工大学 2024 届应用化学本科 → 制造业/化工研发方向）。
> **定位**：本插件"标准简历"的形态参照——写作前的第一份参照物（优先级高于 web 检索语料，同义规则冲突以本文件为准）。
> 隐私处理：姓名/照片信息已脱敏；结构、句式、量化逻辑为可复用标准。

## 一、版式形态（一眼特征）

- **无照片**、右侧浮动智能栏（姓名/年龄/性别/政治面貌/电话/邮箱/所在地——信息全，无冗余项）
- 章节顺序：教育经历 → 实习经历 → 项目经历 → **校园经历** → **技能优势** → 自我评价；左侧顶部"求职岗位"标签
- 全文**加粗克制**：仅岗位关键词（如"肉制品行业研发工程师"）+ 证书/奖项名词加粗，正文不铺粗
- 单页，行距舒适，条数多但每条短（每段 2-4 条）

## 二、章节写法标准（逐节对照）

### 教育经历（2 行）
- 行1：`学校 · 专业（本科） · 时间`（左）+ 学位（右）
- 行2：主修课程（**6-8 门为上限**，按岗位裁剪，不写分数）；另一行"获得奖励：XXX"（**一句话**，不展开）
- 不做多余核验（GPA 有则写、无则不占位）

### 实习经历（分段，每段 3 条）
- 每段：`公司 · 岗位 · 时间`；**每段 3 条**，每条 = 场景/任务 + 动作 + 量化（"完成 XX 项""处理 XX 单据""累计 XX 批次"）
- 首条常用"从事XX的XX，逐步掌握XX"（成长叙事）；中间条写具体动作与量化；末条写结果/收获
- 机构口径：数字口径统一（"累计处理单据数量"与"使用Excel...配合"表述务实）

### 项目经历（标注级别 + 角色）
- `项目名（级别） · 角色 · 时间`，如"（校级创新训练）国家级（编号XX） · 项目核心人员"
- 描述 3 条：任务简介 → **直接完成XX**（个人贡献）→ 小组合作完成（协作角色）
- 量化：完成量/组合成功数量/节省时间/覆盖范围

### 校园经历（1-2 段，学生工作）
- 每段：`组织/部门 + 职务 + 时间`；**3 条**，各带量化（"累计宣传XX次""推送XX条""累计处理日常事务XX""制定XX制度""组织XX场"）
- 学生干部写法：职务 + 负责事项 + 量化产出 +（制定规范类"从0到1"事件更佳）

### 技能优势（5-7 条，能力域分区）
- 每条：`能力域：熟练掌握XX（工具），可用于XXX（用途）`——工具带名称、落于用途
- 典型分域：分析仪器操作 / 科研数据处理 / 实验室安全与管理 / 办公与多媒体 / 语言与编程基础 /（按专业展开）
- 无"了解/熟悉"混层（样例全为"熟练掌握"，分层在本插件按范本五规律）

### 自我评价（3-4 行，结论式）
- **不与正文重复数字/履历**，写"能力结论 + 个性品质"：
  "X 技能与创新能力：具备...；数据与呈现能力：...；工作品质：踏实验证、认真负责；**希望加入贵公司**"
- 每行一句，行首能力标签不必再重复岗位词

## 三、机构标准八条（我方的 0-7 与它对齐处）

| 机构标准 | 与本插件清单对照 |
