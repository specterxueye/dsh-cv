# 按缺口选题的建档题库

这是备用题库，不是七轮必经流程。已有材料先提取摘要，集中核对冲突与关键缺失，不重复问已知学校、日期、职位和项目。每轮选择当前最有价值的一小组问题，可跳过、暂不确认或稍后补充。

| 类别 | 必要时询问 |
|---|---|
| 目标与输入 | 目标岗位、城市、批次、已有简历和允许读取的材料 |
| 基本资料 | 称呼与必要联系方式；就业状态、身份不默认；政治面貌只在必要且本人愿意时确认 |
| 教育 | 学校、专业、时间、可用成绩/课程/荣誉；材料中已知信息不重问 |
| 工作 | 单位、时间、实际任务、责任边界、交付与来源 |
| 项目 | 真实/课程/竞赛等性质、本人动作、技术取舍、结果口径、团队分工 |
| 技能与其他 | 实际使用层次、证书、可说明的作品、相关实践 |
| 偏好与政策 | 页数、栏目、排除项、地点和调配意愿 |

个人史实不给虚构的推荐答案。可提供中性选项“独立负责 / 负责一部分 / 协助 / 待确认”，不预选强角色。推荐只用于策略选择，并说明依据；用户未答不能等于确认。

用户明确确认可以成为来源，材料强度单独记录；没有材料不代表不会或没做过。估计数字继续 pending，真实已确认的定性职责可用。题目答完与否不决定是否建档完成；满足本次目标所需事实即可进入方案，剩余事项放 pendingFacts。

手机号等只在必要且获准时读取或记录；经 DSH 发送的内容会由所配置模型处理，不宣称只在本机。
