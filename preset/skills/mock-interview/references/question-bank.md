# 题库（通用 · 按事实源具体化后使用）

> 用法：**不要照读题目**。每条题目都要结合用户真实经历具体化——
> "讲一个你克服困难的经历" → "你在 <具体项目> 里遇到 <具体卡点> 时是怎么处理的？"
> 题目只有在能对应到事实基线里的真实条目时才有训练价值。

## 一、行为面试 BQ（12 题 + 追问）

| # | 题目 | 追问链 |
|---|---|---|
| 1 | 讲一个你最有成就感的项目，你具体做了什么？ | 哪一步是你独立完成的？→ 结果数据什么口径？→ 如果重来会改什么？ |
| 2 | 讲一次你和他人意见不一致的经历 | 对方立场是什么？→ 你怎么说服/被说服？→ 最后结果谁受益？ |
| 3 | 讲一次失败或没做成的经历 | 失败点在哪一步？→ 你当时怎么补救？→ 现在怎么避免？ |
| 4 | 讲一次在时间/资源不够的情况下完成任务的经历 | 你砍掉了什么？→ 依据是什么？→ 交付质量如何保证？ |
| 5 | 讲一次你主动发现并解决的问题（没人要求你做） | 你怎么发现的？→ 推动过程中遇到什么阻力？→ 谁受益？ |
| 6 | 讲一次你带团队/协调多方的经历 | 团队几人不服管怎么办？→ 你怎么分配任务？→ 进度怎么盯？ |
| 7 | 讲一次你从零学一个新东西并用到实际里的经历 | 学习路径是什么？→ 卡在哪？→ 用到什么结果上？ |
| 8 | 你怎么处理多任务并行/优先级冲突？ | 你的排序依据？→ 有没有出过事故？→ 后来怎么改进？ |
| 9 | 你做过的最枯燥/最琐碎的工作是什么，怎么看待它？ | 你怎么保证不出错？→ 有没有想办法自动化/提效？ |
| 10 | 讲一次你被批评/收到负面反馈的经历 | 你当时怎么反应？→ 具体改了什么？→ 后续有没有验证改进？ |
| 11 | 你为什么选这个岗位/这个方向？ | 你为此做过哪些准备？→ 如果不做这个你会做什么？ |
| 12 | 你未来 3 年的规划？ | 你希望第一年学到什么？→ 如果岗位和预期不符怎么办？ |

## 二、技术面（按项目深挖 · 4 类）

**A. 数据与实验类**
- 数据集多大？怎么划分？标注质量怎么保证？（追问：脏数据/类别不均衡怎么处理？）
- 你这个指标是在什么条件下测的？样本量？怎么排除过拟合？（追问：换数据集还成立吗？）
- 对比实验做了几组？基线是什么？为什么选它做基线？

**B. 工程实现类**
- 这个功能的整体架构是怎样的？（追问：数据流向？失败重试？）
- 你说做了性能优化，原来慢在哪？你怎么定位的？（追问：优化前后怎么量化？）
- 数据的存储/一致性怎么保证？（追问：并发/异常路径？）
- 测试怎么做的？覆盖到什么程度？（追问：有没有测不出来的场景？）

**C. 排障类（★ 技术面最爱问）**
- 讲一个你排查最久的 bug：现象 → 假设 → 怎么缩小范围 → 根因 → 修复 → 如何防止复发。
  （追问链：当时为什么先怀疑 A 而不是 B？→ 有没有写测试守住？→ 同类问题还可能在别处出现吗？）
- 有没有"看起来好了但其实没修好"的经历？怎么发现的？

**D. 协作与交付类**
- 接口怎么定的？后端改字段你怎么办？
- 需求临时变更你怎么处理？
- 你的代码/文档别人能接手吗？（追问：你写过什么文档？）

## 三、央国企 / 事业单位结构化

| 维度 | 常见题 | 注意 |
|---|---|---|
| 政治素养 | 政治面貌与发展阶段？参加过哪些组织生活/学习？ | 按实际阶段如实说，时间不确定就不说时间 |
| 稳定性 | 为什么选我们？能否接受基层/异地/轮岗？职业规划？ | 表达长期发展意愿；**不要**说"想快速晋升" |
| 组织服从 | 如果分配的岗位和你的专业不完全对口？ | 服从 + 用学习能力/相近经历支撑 |
| 规范意识 | 你怎么看待流程和审批？有没有按规范办事的经历？ | 举真实流程/文档/保密经历 |
| 团队与集体 | 学生工作/志愿服务经历，遇到不配合怎么办？ | 用组织协调的真实事说 |
| 家庭与个人 | 家庭成员情况、能否长期在本地 | 按实答，不主动展开敏感关联（如亲属单位与实践单位重合） |
| 价值观 | 你怎么理解"责任"？遇到利益冲突怎么办？ | 具体事 + 结论，不要口号 |

## 四、出题纪律（出题人自查）

- [ ] 每道题都能在事实基线里找到对应条目（否则删掉或换成真实条目）
- [ ] 没有问"你有没有做过 X"而 X 在基线里不存在
- [ ] 高压模式的追问不超过 3 层（超过就变成刁难，训练价值下降）
- [ ] 涉及实习单位/证明人/家庭等敏感项，只在用户主动提到后追问
- [ ] 复盘里的"改善版"没有新增事实
