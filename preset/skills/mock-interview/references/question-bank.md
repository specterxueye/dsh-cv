# 面试题库：区分经历、知识与假设

| 类型 | 提问方式 | 边界 |
|---|---|---|
| 经历追问 | 你在已确认项目中具体做了什么？如何验证？ | 不假定用户负责未确认的部分 |
| 行为题 | 从真实经历选一次协调、失败、取舍或改进 | 没有现成案例时可共同梳理，不代造个人经历 |
| 知识题 | JD 的某项概念如何工作？适用条件是什么？ | 可以问没在项目用过的 Redis 等，明确是知识评估 |
| 情景题 | 假设发生某种故障，你会怎样定位？ | 明确为假设，回答不写回履历 |

可选追问：对象和责任边界、方案选择、替代方案、验证方式、失败与恢复、结果口径。追问强度按用户选择，不把没做过某技术变成诱导编造的经历题。

一次一题，先等回答，再核对概念、事实一致性和表达。复盘给出保留原事实的改善版与下一步练习，未确认的新经历不写入事实基线。
